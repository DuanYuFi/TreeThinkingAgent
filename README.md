# TreeThinkingAgent (TTA)

TreeThinkingAgent，简称 TTA，旨在为复杂任务提供一种可组织、可追踪、可演化的思维能力。它将任务处理过程建模为树结构：每一个问题、目标、假设、决策、证据和中间结论都可以作为树上的节点被记录、展开、回溯和重组。

这个项目关注的不只是“生成答案”，而是构建一种更适合复杂任务的认知框架，使智能体能够在长周期、多分支、高不确定性的任务中保持上下文稳定、推理路径清晰，并持续管理自己的记忆。

## 核心理念

复杂任务往往不是线性的。它们通常包含多个子目标、多条探索路径、反复变化的约束条件，以及需要长期保留的背景信息。TTA 使用树结构来表达这种复杂性：

- 根节点表示任务的总体目标或核心问题。
- 分支表示不同的思考方向、方案、假设或子任务。
- 叶子节点表示阶段性结论、待验证判断、行动结果或沉淀下来的经验。
- 节点之间可以通过引用建立非树状关系，用来表达跨分支的关联、依赖、冲突或复用。

通过这种方式，智能体可以把复杂任务拆解为结构化的思维过程，而不是依赖一段不断增长、难以管理的上下文文本。

## 记忆能力

TTA 的重点在于记忆管理。项目希望让智能体具备更接近长期工作的能力：知道什么信息应该短暂保留，什么信息应该长期沉淀，什么信息属于同一类问题，以及不同记忆之间如何相互引用。

### 长记忆

长记忆用于保存对未来任务仍然有价值的信息，例如：

- 用户的长期偏好和稳定约束。
- 项目的背景、目标和架构原则。
- 已验证的经验、结论和设计决策。
- 重要任务的历史脉络和结果。

长记忆强调稳定性和可复用性，帮助智能体在跨会话、跨任务的场景中保持连续性。

### 短记忆

短记忆用于支持当前任务的即时推理，例如：

- 当前正在处理的子目标。
- 最近读取或生成的信息。
- 临时假设、待办事项和中间状态。
- 当前分支中的局部上下文。

短记忆强调灵活性和及时性，可以随着任务推进被更新、合并、降级或清理。

### 记忆分类

为了避免记忆堆积和语义混乱，TTA 将记忆按类型进行分类管理。不同类型的记忆可以有不同的生命周期、检索策略和更新规则。

常见分类包括：

- 目标记忆：记录任务目标、成功标准和约束条件。
- 知识记忆：记录事实、概念、外部资料和项目背景。
- 决策记忆：记录已经做出的选择及其原因。
- 过程记忆：记录执行步骤、尝试路径和失败经验。
- 偏好记忆：记录用户风格、工作习惯和交互偏好。

分类后的记忆更容易被检索、比较和维护，也更适合在树结构中被挂载到不同节点。

### 记忆交叉引用

复杂任务中的信息经常跨越多个分支。例如，一个设计决策可能影响多个子模块，一个失败经验可能适用于多个后续尝试，一个用户偏好可能同时约束多个任务。

TTA 支持记忆之间的交叉引用，用来表达：

- 某个节点依赖另一段记忆。
- 两个思考分支共享同一条事实或假设。
- 一个结论与另一个结论存在冲突。
- 某段长期记忆来源于某次短期任务。
- 某个决策可以被多个后续任务复用。

交叉引用让记忆不再只是孤立文本，而是可以形成可导航的知识网络。

## 目标

TTA 的目标是探索一种面向复杂任务的智能体思维基础设施，使智能体能够：

- 结构化地拆解和推进复杂任务。
- 在长时间任务中保持上下文一致。
- 区分短期工作记忆和长期沉淀记忆。
- 对记忆进行分类、检索、更新和清理。
- 在不同思考分支和历史经验之间建立引用关系。
- 支持回溯、复盘、比较和持续学习。

## 适用场景

TTA 适用于需要长期上下文和多路径推理的任务，例如：

- 复杂软件项目规划与实现。
- 多阶段研究和资料整理。
- 长周期个人或团队助理。
- 需要持续复盘和知识沉淀的智能体系统。
- 多方案比较、决策追踪和任务分解。

## 项目状态

当前项目处于概念和基础能力设计阶段。后续可以围绕以下方向继续扩展：

- 树结构思维节点的数据模型。
- 长记忆与短记忆的存储机制。
- 记忆分类与标签系统。
- 记忆引用、检索和冲突检测。
- 面向智能体的任务执行流程。
- 可视化的思维树和记忆网络。
